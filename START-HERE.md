# Checkmate Club — source export

A chess site with three modes: **Play vs Computer**, **Solve Puzzles**, and **Play a Friend**.

Built with TanStack Start (React 19 + Vite), Tailwind CSS v4, chess.js, and a Supabase-compatible
backend for friend rooms.

---

## What's inside

| Path | What it does |
| --- | --- |
| `src/routes/index.tsx` | Home page listing the three modes |
| `src/routes/computer.tsx` | Play vs Computer — 10 difficulty levels |
| `src/routes/puzzles.tsx` | Endless random puzzles with hints, skip, streak |
| `src/routes/friends.tsx` | Create / join a room with a 5-digit code |
| `src/components/ChessBoard.tsx` | The board: click or drag to move, promotion picker, check/last-move highlights |
| `src/components/MoveList.tsx` | Move list in algebraic notation |
| `src/components/SiteHeader.tsx` | Top navigation |
| `src/lib/engine.ts` | The chess engine: negamax + alpha-beta search, piece-square tables, quiescence search, 10 difficulty presets |
| `src/styles.css` | Theme tokens (board colours, dark green/gold palette) |
| `src/integrations/supabase/` | Backend client + auth middleware (auto-generated by Lovable) |

## Difficulty levels (Play vs Computer)

Defined in `src/lib/engine.ts` in the `LEVELS` array:

| Elo | Name | Search depth |
| --- | --- | --- |
| 200 | Pawn Pusher | 1 |
| 450 | Rookie | 1 |
| 800 | Club Novice | 2 |
| 1000 | Casual | 2 |
| 1500 | Club Player | 3 |
| 1800 | Expert | 3 |
| 2000 | Candidate Master | 4 |
| 2300 | Master | 4 |
| 2600 | Grandmaster | 5 |
| 2900 | World Champion | 6 |

Each level also has a `noise` value (how much it randomises its choice) and a `blunder`
chance (probability of playing a random legal move). Those two knobs are what make low
levels actually lose — depth alone does not. Ratings are approximate, not measured.

To add or change a level, edit the `LEVELS` array; the picker on the Computer page is
generated from it.

## Setup

1. **Install dependencies**

   ```bash
   bun install     # or: npm install
   ```

2. **Point it at a backend.** Copy `.env.example` to `.env` and fill in your project URL
   and publishable key. Friend rooms need **Realtime with Broadcast enabled** on that
   backend.

3. **Run it**

   ```bash
   bun run dev     # or: npm run dev
   ```

   Open the printed URL (usually `http://localhost:8080`).

4. **Checks**

   ```bash
   bun run lint
   bun run test
   bun run build
   ```

## Things to know before you use it

- **No accounts, no sign-in is required to play.** All three modes are free and open.
- **Puzzles come from the public Lichess API** (`https://lichess.org/api/puzzle/next`).
  They are served at random — there is no level filter, and you need an internet
  connection. Puzzle ratings are shown for information only.
- **Piece images are loaded from Lichess' CDN** (cburnett set). Offline, the board renders
  empty. To go fully offline, drop your own SVGs into `public/` and change the `src` in
  `src/components/ChessBoard.tsx`.
- **Friend rooms are ephemeral.** The 5-digit code lives only in memory inside a Realtime
  channel — nothing is written to a database. The room survives only while the host is
  connected; if the host closes the tab the room is gone and a new code is needed. A
  rematch works while both are still connected.
- **The engine runs in your browser.** The strongest levels (depth 5–6) can take a few
  seconds per move, and there is a 4-second safety cutoff so it never hangs.
